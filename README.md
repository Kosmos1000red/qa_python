Описание реализованных тестов:

test_add_new_book: Проверка добавления книг с разными длинами названий (от пустой строки до 41 символа). Также проверяется защита от дубликатов — повторное добавление одной книги не увеличивает количество элементов в коллекции.
test_set_book_genre_valid_and_invalid: Позитивный сценарий установки жанра существующей книге. Проверяет возвращаемое значение метода (None) и успешную установку жанра. 
test_get_book_genre: Получение установленного жанра по названию книги.
test_get_books_with_specific_genre: Фильтрация списка книг по жанру.
test_get_books_genre: Проверка того, что публичный геттер .get_books_genre() возвращает словарь со всеми добавленными книгами.
test_get_books_for_children_excludes_age_rating: Проверка метода получения детских книг.
test_add_book_in_favorites: Добавление книги в избранное. Проверяется возможность повторного вызова метода (дубликаты не создаются).
test_delete_book_from_favorites: Удаление книги из избранного.
test_get_list_of_favorites_books_empty_and_filled: Проверка вывода пустого и заполненного списка избранных книг.
