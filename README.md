Описание реализованных тестов:

test_add_new_book - проверка успешного добавления книг, ограничение длины названия (до 40 символов включительно), запрет пустых имен и защита от дубликатов (через параметризацию).
test_set_book_genre_valid_and_invalid - установка существующего жанра из разрешенного списка, игнорирование несуществующего жанра или попытки задать жанр отсутствующей книге.
test_get_book_genre - получение установленного жанра существующей книги и отсутствие значения (None) для неизвестной/несуществующей книги.
test_get_books_with_specific_genre - фильтрация по жанрам, включая случаи с нулевым результатом (через параметризацию).
test_get_books_genre_returns_dict - проверка того, что метод возвращает словарь всех добавленных книг.
test_get_books_for_children_excludes_age_rating - исключение из детской подборки жанров «Ужасы» и «Детективы», а также корректная работа при отсутствии у книги любого жанра.
test_add_book_in_favorites - добавление в избранное только существующих книг, защита от создания дублей при повторном вызове метода.
test_delete_book_from_favorites - удаление книги из избранного, если она там есть, безопасный вызов метода для книги, которой нет в избранном.
test_get_list_of_favorites_books_empty_and_filled - проверка вывода списка избранных книг до и после его заполнения.
test_changing_book_genre - успешная смена жанра на валидный, блокировка установки недопустимых значений (например, не из разрешенного списка).
